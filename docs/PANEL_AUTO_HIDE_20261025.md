# 每个收纳区独立自动隐藏

入口：收纳区右上角「此栏样式与布局」→「显示」→「自动隐藏」。默认关闭，每栏独立保存；开启后可设置移出后的延迟，范围 0.2–5 秒，默认 0.8 秒。鼠标停留在原收纳区矩形内约 120 毫秒后显示，短暂划过不会展开。

隐藏只改变瞬时渲染状态，不修改 `layout.visible`，不卸载收纳内容，不改动文件。隐藏的面板从原生窗口命中区域排除，不用透明覆盖层挡住桌面。后台在功能启用期间通过 Windows 光标位置和桌面客户区原点发送只读位置事件，前端换算 DPI 后判断对应区域。后台检测不依赖被遮挡 WebView 的 JavaScript 定时器，也不记录鼠标轨迹；全部关闭时停止采样。旧检测任务的取消不能终止新任务。

重命名、设置、批量操作、菜单、原生系统菜单、拖放及移动面板时，正在操作的面板保持显示。关闭操作后重新开始隐藏延迟。读取光标失败时保持显示，确保还能访问设置。动画统一使用 Motion，设置复用 Nova Switch 和 Slider，没有新增依赖。

从控制中心「在桌面查看」或「定位」会临时显示对应收纳区，再恢复自动隐藏；显式隐藏仍使用原有可见性配置。

验证包含时序状态、每栏独立性、DPI 与负屏幕坐标、跟踪引用计数、陈旧事件、取消和恢复，以及配置导入校验。浏览器入口 `tests/fixtures/panel-auto-hide.html` 使用模拟光标事件和内存配置，可检查显示状态及提交给原生层的命中矩形；不修改个人文件。
