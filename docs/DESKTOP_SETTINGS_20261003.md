# 桌面就地配置 · 2026-10-03

每个桌面收纳栏和快捷启动标题上的设置按钮直接打开旁边的浮动面板，提供样式与布局。收纳栏的更多菜单也进入同一面板，不打开控制中心。一次只编辑一个栏，修改立即生效并自动保存；可以关闭面板或在其他面板内点击关闭。

标题栏简化：收纳区、快捷启动不再显示名称前的装饰图标；便签、待办、时钟和剪贴板不再显示「签 / 办 / 时 / 剪」类型徽章。控制中心概览预览同步简化，名称与原有操作保持。

控制中心移除「收纳栏设置」页和概览卡片上的独立设置入口，保留来源管理、显示器布局和「全局外观」。全局风格默认被所有栏继承；独立设置仅覆盖明确修改的字段。桌面「恢复全局风格」删除此栏覆盖并重新继承；全局页「统一所有收纳栏」经确认后清除全部栏的外观覆盖，保留位置、大小、文件显示布局和引用。

桌面浮动面板使用 `nestra-hit` 参与原生命中区域，定位依据当前面板和虚拟桌面可视范围；内容高度受视口限制，支持内部滚动。输入与下拉控件沿用桌面借用/归还键盘焦点机制，卸载输入时归还。配置仍保存在 `panelLayouts`，不新增持久化格式；已有独立样式原样载入。
