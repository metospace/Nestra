# 桌面收纳栏体验更新 · 2026-10-03

在第一阶段功能重构基础上，补齐桌面操作层和控制中心的显示设置。完整 Dock 仍按原方案作为后续阶段。

## 本轮改动

- 收纳栏改为紧凑标题、按需展开的搜索和「更多」菜单；低频筛选、刷新、隐藏及折叠放入菜单，底部保留真实移动/只浏览提示。
- 新增「收纳栏设置」，桌面标题上的设置按钮直接定位当前栏；分为内容、样式、布局。每个栏可独立设置材质、圆角、边界、不透明度和背景颜色，也可恢复全局默认。
- 图标 24–64 px、项目间距 0–24 px、文件名 1–3 行、紧凑/舒适、网格/列表和列数设置；文件组使用自己的布局与样式身份。
- Ctrl 多选、Shift 连选、空白处拖动框选、全选可见项目；批量固定引用、批量移动、批量放回桌面以及多项目拖放。失败项目保留选择供重试。
- 数据页和收纳栏菜单提供移动记录入口。本次运行保存最近 50 次成功移动；退出后清空。撤销检查 Windows 文件身份和文件元数据，原目录不存在、原位置已有同名文件、文件修改/替换/再次移动时拒绝操作。目录保留其身份，内容改动不被撤销。
- 文件移动使用 Windows 不覆盖目标的原子重命名；跨卷复制也拒绝已有文件和已有目录，避免合并或覆盖其他进程新建的目标。
- 搜索先按精确名称、去扩展名精确名称、前缀、名称包含、路径匹配排序；最近成功打开的项目用于同等级排序。本次运行的启动记录不写盘。
- 搜索每批显示 24 项，可继续显示和用方向键浏览；Everything 与映射查询各加载最多 200 项，合并结果最多 500 项，提示查询上限。没有把有限批次称为完整全盘分页。
- 快捷启动改为图标网格/列表，使用相同的独立显示设置；桌面可直接启动集合，移除按钮明确只移除引用；取消原来的 32 项显示上限。
- 概览页展示真实桌面栏预览，提供定位、隐藏恢复和直接设置；删除大面积统计卡片，收紧首页层级。
