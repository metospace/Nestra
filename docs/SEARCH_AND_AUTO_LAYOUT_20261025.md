# 查询回传兼容与完整图标布局

Everything 查询窗口按官方 SDK 设置独立接收窗口的 WM_COPYDATA 权限，兼容从提升权限的安装程序启动 Nestra 后接收普通 Everything 进程的回复。每次查询使用独立回复标识，并对非零发送窗口检查提供方进程；保留长度和结构校验。最长等候改为 5 秒，空关键词连接检查也需要实际回复。参考官方 Everything SDK 的 `_Everything_ChangeWindowMessageFilter` 和 QUERY2W 协议。

真实索引验证：使用“纵横”得到 27 条匹配（测试只返回前 5 项，只记录计数）；既有旧链路在独立普通测试进程中也能查询，因此不把权限差异断言为所有超时的唯一原因。新修复针对应用运行上下文的兼容问题。若查询失败，界面明确显示不可用与重试入口，不把失败误写成零匹配。

收纳区改为自动宽高，使用图标大小、间距、名称行数和当前显示器空间计算完整单元格。原配置自动使用新布局；首选列数仍在此栏设置中调整。宽高交给内容布局，保留标题栏移动。工具栏、搜索、标签、折叠项目和多选工具占用的空间也计入高度。

内容区不显示滚动条。屏幕放不下的项目通过上一页／下一页访问，不能以裁切最后一行代替分页。折叠预览限制为一行完整项目，剩余内容由展开按钮访问。名称仍按用户设置的行数展示，完整名称可通过悬停查看。

验收页 `tests/fixtures/organizer-auto-layout.html` 仅使用内存示例，覆盖六个 64px 图标、200 个项目、640×480 显示器和列表模式。尺寸纯函数测试遍历图标大小、间距、名称行数及密度组合。浏览器读取真实元素边界，六图标和多页场景都没有超出内容区域的单元格。
