# 后续体验修复与验收 · 2026-10-06

用户已授权继续修复。此轮修改前端，遵守真实目录收纳、ID 迁移、串行持久化与桌面命中区规则。

## 已修复

1. 搜索异步补齐：每次应用新结果时读取用户当前选中项，按 ID 保留选择；新结果将该项挤出当前可见条数时自动扩展。应用目录和最近打开记录的后台更新也保留选择。改关键词或范围才重置，过期请求继续丢弃。
2. 在桌面查看：使用独立的查看动作，保留有效位置、尺寸和锁定状态；仅不可访问的布局进行恢复。显示并提高层级，暂停时先恢复桌面，保存成功后隐藏管理窗口；原生恢复或保存失败时保留管理窗口并显示错误。显式“显示并定位”仍保留原有移位语义。
3. 批量操作结果：多选移动、外部路径收纳、多选放回桌面、整理预览统一保留逐项结果，显示全部文件路径和错误原因。自动打开结果弹窗，可关闭后从桌面面板菜单或文件管理页重新查看，可切换本窗口历史操作，只重试失败项。
4. 重试边界：保留原始来源及目标，目标目录改名、重新绑定或来源失效时阻止自动重试；原生移动成功后列表刷新失败单独显示警告，不将成功项标为失败。批量操作串行执行，同时阻止另一个批次启动。文件 ID 迁移继续通过 migrateItemId，保存继续通过现有 persistChain。
5. 首次使用：空且隐藏的系统快捷启动不占用概览。空工作空间显示“新建收纳区”“显示已有文件夹”，分别直达对应表单，说明真实移动与默认只浏览的区别。
