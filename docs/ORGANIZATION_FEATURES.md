# 收纳与组织功能

## 使用

- **收纳区**：在管理器新建，文件拖入会真实移到该收纳区目录。图标单击选中、双击打开；右键可打开、放回桌面、移动到其他区、加入快捷启动。拖出到桌面背景也会移回桌面。
- **拖动提示**：收纳区或映射目录显示移动目标；快捷启动显示“仅引用，原文件不移动”；非接收区域显示不接收提示。
- **文件夹映射**：新建对话框选择“文件夹映射”，输入名称及已有文件夹完整路径。显示直接子项，约每 5 秒刷新，也可手动刷新。拖入会真实移动到该目录。改名只改面板标题，移除映射不移动、不删除目录及文件。
- **分类筛选**：面板选择全部、文档、图片、应用、文件夹、影音、压缩包。仅改变显示范围，不自动移动文件；选择随分区保存。
- **分组标签页**：在管理器给需要合并显示的分区填写相同“标签页组”名称。第一个可见分区提供面板位置，其他分区成为标签页；单击切换，也可直接拖到目标标签。清空组名即可恢复独立面板。活动标签随配置保存。
- **快捷启动**：保存引用路径；即使移除原文件夹映射，也会独立恢复仍存在的引用。文件已不存在时清理失效入口。
