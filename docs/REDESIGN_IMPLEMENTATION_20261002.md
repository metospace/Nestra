# Nestra 第一阶段实施记录 · 2026-10-02

本次按用户批准的设计重构功能入口与 Nuxt UI，保留 Tauri 2 / Vue 3 和真实文件收纳语义。参考设计见 `PRODUCT_REDESIGN_20261002.md`；完整 Dock、正在运行窗口访问和插件扩展仍属于后续阶段。

## 已实施

| 模块 | 运行时能力 |
| --- | --- |
| 控制中心 | 九个独立任务页面，概览状态、常用操作、隐藏内容恢复 |
| 文件与收纳 | 真收纳区、默认只读文件夹映射、桌面分类视图、文件组管理；手动整理先生成文件与目标预览再移动，失败项可重试 |
| 文件组 | 独立面板身份和布局；来源排序、移出不再迁移首个来源的布局；全部来源聚合只浏览，单个来源按自身接收策略拖放 |
| 快捷启动 | 文件与文件夹引用、显示名、顺序、启动集合及成员编辑；保留失联入口、检查可用性和重新绑定；逐项启动结果 |
| 搜索 | 独立可激活窗口；Ctrl+Alt+F；桌面、收纳区、映射递归、开始菜单、AppsFolder 应用目录、Everything 本机 IPC；先显示本地结果，过期请求不覆盖新查询 |
| 小组件 | 便签、待办、剪贴板、时钟；统一编辑、隐藏、恢复、定位；剪贴板记录开关和清空，最多 50 条文本，历史仅在内存 |
| 布局 | 显示器选择、显示开关、锁定、定位；文件组与组件共用表面布局模型；断开显示器保留原布局，重新连接可回迁 |
| 外观 | Nuxt UI 蓝色/slate；浅色、深色；材质、圆角、边界、不透明度和实时预览；桌面菜单、重命名与确认框同步主题 |
| 数据 | 格式 v2；迁移前备份；备份列表、导出、导入验证与恢复预览；恢复前当前配置备份和条件写入；已有真实目录不会被配置恢复重命名；未关联目录可重新关联；外机缺失收纳目录需绑定 |
| 系统 | 暂停桌面、随 Windows 启动、原生图标共存/接管、搜索依赖状态 |

新字段参与三方合并。所有主配置写入经 `persistChain` 串行调用 `savePersistedState`；远端应用仍抑制持久化 watcher。快捷入口保存目标元数据供离线修复，始终为引用，不移动文件。新映射默认只浏览，旧映射迁移保留原接收行为。
