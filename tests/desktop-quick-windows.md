# 桌面快开：Windows 验收

1. 启动 Nestra，在个人或公共桌面放一个测试快捷方式，在收纳区放一个测试文件，并准备一个已映射目录。不要使用生产文件。
2. 保持记事本在前台，按 Ctrl+Alt+Space。「桌面快开」应在记事本上显示，输入框立即可打字，不应触发显示桌面，收纳层不应抬高。
3. 空关键词应能直接浏览，切换「桌面／收纳区／映射文件夹」应隔离来源。Windows 隐藏项目和重复路径不应在全部列表里重复出现。
4. 输入中文，确认输入法候选期间的 Enter、方向键、Esc 不会误启动或关闭弹窗。输入完成后按 ↑↓、Enter，应打开所选文件。用鼠标点击原始程序快捷方式，确认启动参数不丢失。
5. 按 Esc 或点击其他应用应关闭弹窗。新增一个桌面测试文件后再次按 Ctrl+Alt+Space，应列出新文件并清除上次关键词。扔掉已扫描的测试文件再打开该结果时，应显示错误，不移动或删除其他文件。
6. 验证托盘「桌面快开」也能打开，Ctrl+Alt+F 仍进入原有全局搜索。测试结束后删除自己添加的测试数据。
7. 在「文档」测试区放真实文件夹和一个指向另一文件夹的原始 .lnk。分别单击卡片、键盘选择后按 Enter，应直接在资源管理器打开准确路径，不切到快开窗内的子目录。用另一个带可见参数的应用 .lnk 验证仍保留启动参数。先用托盘入口排除全局快捷键的影响。
8. 记录从点击到目标 Explorer 地址/应用窗口能操作的时间；预览日志 quick-launch-dispatch 只计算 Nestra 到 Windows Shell 返回的时间（不记路径），不等同于应用加载完。比对冷启动与已启动时打开；若测试慢，分别核对本地和映射路径。
